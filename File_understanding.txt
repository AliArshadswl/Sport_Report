

## 📌 **PatchHAR-Sports LaTeX Project Setup (For ChatGPT)**

I am using a custom LaTeX template with the following structure:

```
project/
   document.tex
   coversheet.tex
   examples/
      config.tex
   core/
      report-template.cls
      packages/
         style/
            font.sty
            header.sty
            page_numbering.sty
            section.sty
            subsection.sty
            subsubsection.sty
            cover-page.sty
         layout.sty
         biblio.sty
         style/code.sty
   assets/
      img/
         background.png
         paper-clip.png
```

### ✔ Important Rules

* The main document is **document.tex**.
* The template loads config from:

  ```
  \input{examples/config}
  ```
* Cover page is generated by **coversheet.tex**.
* Template behavior (fonts, headers, sections, cover design) is controlled by files in:

  ```
  core/packages/style/
  ```
* To modify:

  * **Document title** → edit `examples/config.tex`
  * **Author** → edit `examples/config.tex`
  * **Company** → edit `examples/config.tex`
  * **Cover background** → replace `assets/img/background.png`
  * **Logo** → replace `assets/img/paper-clip.png`
  * **Section colors** → edit `mainColor` in `examples/config.tex`
  * **Cover page layout** → modify `core/packages/style/cover-page.sty`

### ✔ What I want ChatGPT to do

When I ask for LaTeX output:

1. **Reuse my folder structure**
2. **Do NOT modify the template files unless I ask**
3. **Put new pages/content inside `document.tex`**
4. **Use the template’s color system (`mainColor`)**
5. **Avoid packages that conflict with the template**
6. **If adding new features (like boxes, diagrams), wrap them so they fit my class.**

### ✔ My Template Limitations

* Cannot redefine page geometry or font families.
* Section titles are controlled by template and should not be overridden.
* Floating icon boxes may break layout — use tcolorbox with stable margins.
